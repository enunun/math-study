サイトの記事で使っている図と同じ形式の図を，ブラウザの上で作る．作った図は，描画する内容(シーンと呼ぶ)を定義したJSONと，TikZとして取り出せる．編集中の図は，このブラウザに保存される．

## 使い方

- 「見本」か「テンプレート(図)」から出発する．見本は，そのまま使える完成した図である(記事の図と，トーラスやテイラー展開などの図)．
- 「テンプレート(図)」は，出発点になる図を読み込む．空の図，座標軸と原点$O$だけの図，それに格子を足した図が，平面と空間の両方にある．
- 「テンプレート(部品)」は，正多角形・2次曲線・フラクタル・ベジエ曲線・正多面体・2次曲面など，種類ごとにまとめた部品を，選んで今の図に加える．識別子は，重ならないように自動で付け替える．
- 「フォーム」で，図の種類と範囲，オブジェクトを設定する．オブジェクトは，一覧から選んで設定し，並びの変更と削除もできる．
- 点は，その点を使うベクトルや線分より前に置く．並びは，描く順と，参照の順である．
- 「編集中の図」と「プレビュー」の，2つの図が並ぶ．「編集中の図」は，格子と座標軸を，実際に描かれるオブジェクトと見分けやすいよう灰色の点線で示す．平面の図の座標軸には，読みやすいように目盛も足す．「プレビュー」は，実際の出力(TikZやJSONの書き出し)と同じ，補助のない図である．
- 空間の図では，「編集中の図」をドラッグすると，方位角と仰角が変わり，見る向きを変えられる．
- 曲面と球には，「ワイヤーフレームを表示」で，曲面の上に引いた`u`一定・`v`一定の断面(球では経線と緯線)を足せる．曲面では，「ワイヤーフレームの刻み」で，断面を引く間隔を`u`方向と`v`方向で別々に決められる．断面は，刻みの整数倍の所に引く(たとえば刻み`pi/6`なら，$\pi/6$の倍数の所)．空欄なら，定義域の幅の4分の1である．ベジエ曲面には，さらに「制御点の網を表示」で，形を決める制御点どうしを結んだ線を足せる．どちらも色や線の種類を選べ，実際の出力にそのまま現れる．
- 「曲線(ベジエ)」と「曲面(ベジエ)」は，式の代わりに，制御点で形を決める曲線と曲面である．制御点は，JSONの配列として「制御点」の欄に書く．平面の曲線は`[x, y]`，空間の曲線と曲面の各制御点は`[x, y, z]`の座標である．
- 「曲線(スプライン)」は，式の代わりに，並べた点をすべて順に通る曲線である．点は，JSONの配列として「通る点」の欄に書く．座標の書き方は，「曲線(ベジエ)」と同じである．
- 「接線」(平面)と「接平面」(空間)は，ほかのオブジェクトに接する線と面である．「接する対象」で，接するグラフ・曲線・曲面を選び，「接する点」で，接する場所(グラフや曲線なら変数の値，曲面なら2つの変数の値)を決める．向きは自動で求まるので，指定しない．接平面には，広さを「半径(cm)」で決める．
- 「フラクタル」は，反復関数系(IFS)で作るフラクタル図形である．「基本図形の点」に，並進・回転・拡大縮小・せん断を組み合わせた「反復の変換」を，「再帰の深さ」の回数だけ施す．基本図形と変換は，JSONの配列として書く．テンプレートのフラクタルは，1辺1の図形の上で定義し，「変換」の拡大縮小で大きさを決めている．
- 「正多角形」(平面)は，辺の数と中心と「半径(中心から頂点まで)」が決める正多角形である．底辺は水平に置く．「多角形(頂点)」は，頂点を座標か点の名前で並べた多角形である．どちらも「塗りつぶし」で面を塗れる．
- 多くのオブジェクト(点・線分・グラフ・曲線・多角形・フラクタル・格子・曲面・正多面体など)は，「変換」で動かせる．「手順」から平行移動・回転・拡大縮小・対称移動などを選んで「手順を足す」と，手順が並びの最後に入る．角度や量は，JSONの欄で直す．手順は上から順に施す．
- 「像(変換した図形)」は，別のオブジェクトを変換した図形を足す．元のオブジェクトはそのまま残り，元を直すと像も変わる．
- 「関数」は，式の中から`f(x)`の形で呼べる関数を定義する．先に定義した関数を使えるので，`f(g(x))`のような合成関数も書ける．
- 「写像」は，点の座標を写す式である．「変換」の手順に選ぶと，曲線や格子を写像で写せる(見本「写像による格子の像」)．
- 「テイラー展開」は，グラフのテイラー展開を，「次数」で打ち切った多項式のグラフである．係数は，式から正確に求まる(特殊関数を含む式は展開できない)．
- 格子は空間の図でも使え，xy平面の上に，範囲を決めて引く．ほかの平面には，「変換」の回転で動かす．
- 「正多面体」(空間)は，種類と中心と「半径(中心から頂点まで)」で決まる正多面体である．頂点と面は自動で決まるので，大きさや位置を変えるには，数を1つ書き換えればよい．
- 「複体」(空間)は，頂点と面でできた，一般の立体である．稜は，面から自動的に決まるので，指定しない．面は，頂点の番号を，外から見て反時計回りに並べる．向きを逆にすると，隠れる稜と見える稜が入れ替わる．
- 数を入れる欄には，式も書ける．式では，`+`，`-`，`*`，`/`，`^`と，`sin`，`cos`，`sqrt`，`exp`，`log`などの関数，定数の`pi`と`e`が使える．ガンマ関数(`gamma`)や誤差関数(`erf`)，ベッセル関数(`besselj0`など)といった特殊関数も使える．`2x`のような省略は使えず，`2*x`と書く．
- 「JSON」では，シーンを直接編集できる．「JSONを読み込む」と「JSONを書き出す」で，ファイルとして出し入れする．書き方の形式は，[JSON Schema](https://enunun.github.io/math-study/schema/scene.schema.json)で決めている．オブジェクトの参照や範囲の大小関係など，スキーマだけでは表せない規則も，各項目の説明に書いてある．
- 「TikZを書き出す」で，図の断片(`.tikz`)を得る．「単体の文書を書き出す」で，そのままコンパイルできるLuaLaTeXの文書(`.tex`)を得る．

## TikZを自分のTeX文書に入れる

断片(`.tikz`)を，`tikzpicture`環境ごと，自分の文書に貼る．プリアンブルには，次の3行を書く．

```latex
\usepackage{tikz}
\usetikzlibrary{arrows.meta}
\usepackage{amsmath}
```

日本語のラベルを使うときは，LuaLaTeXと，LuaTeX-jaを使う．図の見た目は，このページのプレビューと，ほぼ同じになる．ラベルの文字の位置は，プレビューと少しずれることがある．

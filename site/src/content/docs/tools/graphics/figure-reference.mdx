## 式

数を書く所の多くには，式も書ける．式には，四則演算(`+`，`-`，`*`，`/`)，累乗(`^`)，丸括弧を使える．かけ算の記号は省けないので，`2x`ではなく`2*x`と書く．三角関数の角はラジアンで，変換の回転(`rotate`)の角は度である．

式の中では，次の名前を使える．

- 媒介変数(`parameter`)の識別子．
- 関数(`function`)の識別子．`f(x, y)`のように，1個から3個の引数で呼ぶ．
- 先に置いた点の座標．点`P`の座標は，`P_x`，`P_y`(空間の図では`P_z`も)である．
- グラフや曲線，曲面の変数(`var`，`vars`)．そのオブジェクトの式の中だけで使える．

点の位置(`at`)は，点の識別子を位置ベクトルとして扱う式でも書ける．たとえば`(A + B) / 2`は2点の中点である．点どうしの和と差，数と点の積，点を数で割ることだけができる．

サイトの記事で使っている図と同じ形式の図を，ブラウザの上で作る．作った図は，描画する内容(シーンと呼ぶ)を定義したJSONと，TikZ，画像として取り出せる．編集中の図は，このブラウザに保存される．

## 使い方

- 「見本」か「テンプレート(図)」から出発する．見本は，そのまま使える完成した図である(記事の図と，トーラスやTaylor展開などの図)．見本は，平面と空間に分け，その中を種別(関数とグラフ，曲面，結晶など)で分けてある．平面か空間，種別，見本の順に選び，「読み込む」を押す．
- 「テンプレート(図)」は，出発点になる図を読み込む．空の図，座標軸と原点$O$だけの図，それに格子を足した図が，平面と空間の両方にある．空間の格子には，$xy$平面の格子と3次元の格子がある．
- 「テンプレート(部品)」は，正多角形・2次曲線・フラクタル・Bézier曲線・正多面体・Bravais格子・2次曲面など，種類ごとにまとめた部品を，選んで今の図に加える．部品は，図形・曲線・曲面・結晶の分類に分かれ，分類の中では種類ごとに見出しが付く．識別子は，重ならないように自動で付け替える．媒介変数と関数は，名前が空いていればそのまま使い，付け替えたときは式の中の名前も書き換える．
- Bravais格子のテンプレートは，平面の5種類と空間の14種類の単位胞である．格子定数(長さ$a$，$b$，$c$と角度)は範囲のある媒介変数なので，スライダーで胞の形を変えられる．角度は度で書く．頂点の格子点は青，体心・面心・底心の格子点は赤で描く．
- 「フォーム」で，図の種類と範囲，オブジェクトを設定する．オブジェクトは，一覧から選んで設定し，並びの変更と削除もできる．
- 点は，その点を使うベクトルや線分より前に置く．並びは，描く順と，参照の順である．
- 「編集中の図」と「プレビュー」の，2つの図が並ぶ．「編集中の図」は，格子と座標軸を，実際に描かれるオブジェクトと見分けやすいよう灰色の点線で示す．平面の図の座標軸には，読みやすいように目盛も足す．「プレビュー」は，実際の出力(TikZやJSONの書き出し)と同じ，補助のない図である．
- 空間の図では，「編集中の図」をドラッグすると，方位角と仰角が変わり，見る向きを変えられる．
- 平面の図では，位置を数で書いた点を，「編集中の図」でドラッグして動かせる．その点を使う点の式やベクトル場なども，一緒に動く．
- 「元に戻す」と「やり直す」で，編集を1つずつ戻し，やり直せる．キーボードでは，Ctrl+Z(macOSでは⌘Z)で戻し，Ctrl+Shift+ZかCtrl+Yでやり直す．文字の入力欄の中では，欄の中の文字の取り消しになる．続けての入力，スライダー，ドラッグ，再生は，まとめて1つの編集として戻る．見本の読み込みも戻せる．
- 「媒介変数」に「スライダーの範囲」を書くと，「編集中の図」の下に，その値を動かすスライダーが出る．「スライダーの刻み」も書くと，値は下端から刻みの倍数だけを取る(整数の指数なら1)．「再生」を押すと，値が範囲の中を繰り返し動き，式でその媒介変数を使うオブジェクトが動く．媒介変数を時間とみなせば，空間の図で4次元の図形を見られる．書き出す図には，その時点の値が入る．
- オブジェクトの種類ごとの項目と書き方，式で使える演算と関数は，<a href="../figure-reference/">図のシーンのリファレンス</a>にまとめてある．フォームの各オブジェクトの「この種類の説明」からも開ける．
- 座標軸・媒介変数・関数・写像のほかのオブジェクトは，どれも「変換」で動かせる．ラベルは位置だけが動く．「手順」から平行移動・回転・拡大縮小・対称移動などを選んで「手順を足す」と，手順が並びの最後に入る．角度や量は，JSONの欄で直す．手順は上から順に施す．
- 「JSON」では，シーンを直接編集できる．「JSONを読み込む」と「JSONを書き出す」で，ファイルとして出し入れする．書き方の形式は，[JSON Schema](https://enunun.github.io/math-study/schema/scene.schema.json)で決めている．オブジェクトの参照や範囲の大小関係など，スキーマだけでは表せない規則も，各項目の説明に書いてある．
- 「TikZを書き出す」で，図の断片(`.tikz`)を得る．「単体の文書を書き出す」で，そのままコンパイルできるLuaLaTeXの文書(`.tex`)を得る．
- 「画像を書き出す」で，プレビューと同じ図を，画像として得る．形式は，SVG，PNG，JPEG，WebPから選ぶ．PNG，JPEG，WebPでは，解像度(150dpi，300dpi，600dpi)も選ぶ．SVG，PNG，WebPでは，「背景を透過する」で，背景を塗らずに書き出せる．JPEGは透過できないので，背景は白になる．色は，明るい背景での色になる．

## TikZを自分のTeX文書に入れる

断片(`.tikz`)を，`tikzpicture`環境ごと，自分の文書に貼る．プリアンブルには，次の3行を書く．

```latex
\usepackage{tikz}
\usetikzlibrary{arrows.meta}
\usepackage{amsmath}
```

日本語のラベルを使うときは，LuaLaTeXと，LuaTeX-jaを使う．図の見た目は，このページのプレビューと，ほぼ同じになる．ラベルの文字の位置は，プレビューと少しずれることがある．

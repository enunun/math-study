## 折り畳み

### 読み込み

MDX のフロントマターの直後に、次の1行を書きます。

```mdx
import { Proof, Detail } from '@/components/fold';
```

### 証明: `<Proof>`

証明の詳細を隠すときに使います。

```mdx
<Proof title="定理 1.2">

ここに証明を書きます。**Markdown** をそのまま書けます。

- 箇条書き
- コード `x + 1`

</Proof>
```

<Proof title="定理 1.2">

ここに証明を書きます。**Markdown** をそのまま書けます。

- 箇条書き
- コード `x + 1`

</Proof>

### 補足: `<Detail>`

行間を埋める補足に使います。

```mdx
<Detail title="なぜ成り立つか">

補足の本文です。

</Detail>
```

<Detail title="なぜ成り立つか">

補足の本文です。

</Detail>

### 属性

| 属性    | 既定    | 説明                                                                 |
| ------- | ------- | -------------------------------------------------------------------- |
| `title` | なし    | 文字列です。ラベル(「証明」「補足」)の後ろに表示する題名になります。 |
| `open`  | `false` | 真偽値です。指定すると、開いた状態で表示します。                     |

`open` の例です。

```mdx
<Proof title="最初から開いている証明" open>

本文です。

</Proof>
```

<Proof title="最初から開いている証明" open>

本文です。

</Proof>

### 入れ子

折り畳みの中に、折り畳みを置けます。

```mdx
<Proof title="外側の証明">

外側の本文です。

<Detail title="内側の補足">

内側の本文です。

</Detail>

</Proof>
```

<Proof title="外側の証明">

外側の本文です。

<Detail title="内側の補足">

内側の本文です。

</Detail>

</Proof>

### 注意

中身を Markdown として解釈させるには、タグの前後に空行が必要です。空行がないと、中身は文字列のまま表示されます。

## 動作確認の項目

- **キーボード**: Tab で証明・補足の行にフォーカスが移り、Enter または Space で開閉します。
- **ブラウザ内検索**: 下の折り畳みの中にある「かたつむり」を、Ctrl+F で検索します。ヒットした折り畳みが自動で開くかは、ブラウザによって異なります。
- **URL のハッシュ**: [折り畳みの中の見出しへ移動](#折り畳みの中の見出し)を押すと、その折り畳みが開きます。ページを開き直して、末尾に `#折り畳みの中の見出し` を付けた URL を開いても、同じです。
- **印刷**: 印刷のプレビューで、閉じた折り畳みの中身も出力されます。
- **スクリーンリーダー**: 「証明 定理 1.2」のように読み上げられ、開閉の状態も伝わります。
